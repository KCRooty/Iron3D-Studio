Iron3D Studio -- antes de empezar
==================================

Gracias por instalar Iron3D Studio, la herramienta de creacion 3D de Static
Forge. Este instalador copiara Iron3D Studio en tu equipo y te dejara elegir
la API de render (Vulkan u OpenGL) que usara por defecto.

Requisitos:
  - Windows 10/11 de 64 bits.
  - Una GPU con drivers Vulkan 1.3 u OpenGL 3.3 actualizados (segun la API
    que elijas en el siguiente paso).

Soporte y contacto:
  - Web del proyecto:  https://staticforge.dpdns.org/i3ds.html
  - Correo de soporte: StaticForge@proton.me
  - Codigo fuente (clean-room, sin codigo de Maxon):
    https://github.com/KCRooty/Iron3D-Studio

Iron3D Studio es software libre (dual MIT OR Apache-2.0) y esta en
desarrollo activo -- revisa el repositorio para el estado mas reciente.
